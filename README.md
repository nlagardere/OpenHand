# OpenHand OS

OpenHand is a lightweight, easy-to-use operating system designed for seniors, beginners, and users with older PCs.  
It features a clear, intuitive interface, large readable fonts, and integrated applications to make computing simple, fast, and enjoyable.

In the long term, OpenHand will be packaged as a **Linux-based kiosk distribution**, providing a complete OS experience with web apps and offline capabilities.

## 🎯 Goals

- Make computing simple and accessible for all ages  
- Provide a clean, modern, and readable interface  
- Ensure smooth performance even on older hardware  
- Build an expandable system where developers can contribute  

## 🧩 Current Features

- User-friendly desktop interface  
- Large, readable fonts  
- Integrated apps:  
  - Basic web browser  
  - Notes app  
  - File manager  
- Simple internal navigation (no new browser tabs)  
- Lightweight and fast  
- Modern and pleasant design  

## 🚧 Development Status

OpenHand is **actively under development**. Contributions from web developers are welcome!  
We aim to continuously add more features, improve the interface, and optimize performance.  
This project will eventually become a full **Linux kiosk OS**, designed to run directly on hardware with minimal setup.

## 🛠️ Technologies

- HTML, CSS, JavaScript (100% front-end)  
- Runs in browser or locally  
- No additional software required  

## ▶️ Installation / Launch

1. Download or clone the repository  
2. Open `index.html` in your web browser  
3. Start using OpenHand immediately
